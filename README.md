# 토코 — Claude Code 안에 사는 쉼표 같은 펫

토코는 Claude Code 터미널의 프롬프트 바로 위에 사는 픽셀 동반자입니다. Claude가 일하는 동안 띠 위에서 숨 쉬고 걸어 다니다가, 작업이 끊긴 틈에 다가와 잠깐 쉬자고 하거나 하던 일을 한 줄로 짚어 줍니다.

토코의 목적은 하나입니다. **AI와 일하며 쌓인 인지 부하를 덜어 주고, 숨을 돌린 뒤 가벼운 마음으로 일에 돌아가게 하는 것**입니다. 그래서 토코는 이렇게 동작합니다.

- 말은 틈에서만 겁니다. 턴이 끝난 직후나 타이핑을 멈춘 뒤에만 말을 걸고, Claude가 일하는 동안에는 입력을 빼앗지 않는 조용한 연출만 합니다.
- 보상은 토큰을 많이 쓴 것보다 쉬는 습관에 줍니다. 토큰 수입은 로그 곡선이라 많이 쓸수록 덜 늘고 하루 상한이 있습니다. 휴식을 받아들인 보상은 상한 밖이고 더 큽니다.
- 잃는 장치가 없습니다. 며칠 안 와도 펫과 코인은 그대로입니다.
- 명령 한 번으로 조용히 할 수 있습니다. 거절이 두 번 이어진 권유는 스스로 빈도를 절반으로 줄입니다.

하지 않는 것도 정해 두었습니다. 토코는 Claude의 작업 내용을 바꾸지 않고 관찰만 합니다. 생산성이 몇 퍼센트 오른다고 약속하지도 않습니다.

## 설치

Claude Code 터미널 세션의 프롬프트에서 입력합니다.

```text
/plugin install toko --marketplace junghyeon95/toko
```

마켓플레이스를 추가할지 물으면 `y`를 누르고, 범위를 고릅니다. 셸에서는 이렇게 설치합니다.

```bash
claude plugin install toko --marketplace junghyeon95/toko
```

데스크톱 앱에서는 프롬프트 옆의 + → Plugins → Add marketplace에 `junghyeon95/toko`를 넣고 Add plugin을 누릅니다. 데스크톱과 VS Code 화면에서는 픽셀 그림 대신 한 줄 글로 보입니다.

## 전체 구조

토코는 Claude Code의 모드(훅 모듈로 화면 · 명령 · 도구를 넓히는 플러그인) 하나입니다. 다른 사람의 펫과 만나는 광장은 선택 기능이고, 광장 서버를 따로 띄웠을 때만 켜집니다.

```text
사용자 ──프롬프트·단축키──▶ Claude Code ──턴·도구 결과·사용량──▶ 토코 모드
                                ▲                                 │
                                └──── 셀 그림 · 말풍선 · 명령 결과 ◀┘
토코 모드 ──펫 대사·의도 결정──▶ 작은 모델(Haiku, 사용자 세션의 자격 증명)
토코 모드 ◀──SSE로 친구·손짓── 광장 서버
토코 모드 ──상태가 바뀔 때 보고──▶ 광장 서버 ──짧은 인사말──▶ LLM 게이트웨이(선택)
```

| 구성 | 역할 |
|---|---|
| 지각기 | Claude Code가 알린 일(턴 시작·끝, 테스트 실패·통과, 커밋, 권한 대기)을 펫이 알아듣는 사건으로 바꿉니다 |
| 시뮬레이션 코어 | 욕구(기운·재미·배고픔·교감)와 기분을 시간에 따라 바꾸고, 지금 할 수 있는 행동 후보에 점수를 매깁니다 |
| 참견 게이트 | 지금이 틈인지 판단하고, 시간당 말풍선 4번 같은 빈도 상한과 방해 금지 시간을 지킵니다 |
| 성격 층 | 작은 모델로 펫의 영혼(이름·성격·말버릇)을 짓고 틈마다 무엇을 할지 고릅니다. 실패하면 규칙과 준비된 대사로 대신합니다 |
| 경제 | 턴 수입과 휴식 보상을 코인으로 바꾸고 상점 지출을 처리합니다 |
| 렌더링 엔진 | 반블록(▀ ▄)과 트루컬러로 장면을 그리고, 화면 전체를 다시 그리지 않고 바뀐 셀만 바꿔 넣습니다 |
| 광장 | 접속한 사람들의 펫이 서로 손을 흔들고, 하트와 간식을 나누고, 다 같이 기지개를 켭니다. 광장 주소를 브라우저로 열면 모인 펫들이 보입니다 |
| 옆 세션 소식 | 같은 컴퓨터의 다른 세션이 답을 마치거나 권한 확인을 기다리면, 지금 보고 있는 세션의 펫이 그 세션의 탭 제목(/rename 이름, 없으면 AI가 지은 제목)을 색으로 짚어 말풍선으로 알려 줍니다. `/toko send` 로 보낸 질문은 그 세션이 답을 마치면 답이 보낸 세션 대화창에 뜹니다(짧으면 그대로, 길면 앞 여섯 줄) |
| 기록 | 휴식 · 테스트 · 커밋 · 편집 줄 수 · 비용을 터미널마다 따로 세고 합쳐서, 업적 · 퀘스트 · 오늘 요약에 씁니다. `/toko today` 는 세션마다 턴 끝에 남긴 질문·답 앞부분으로 오늘 한 일과 진행 중인 일을 일 단위로 정리합니다(닫힌 세션 포함) |
| 터미널 사이 동기화 | 펫 · 보관함 · 설정 · 지갑 같은 공용 상태를 4초마다 저장소와 맞춥니다. 다른 터미널이 바꾼 값은 받아오고 이 터미널이 바꾼 값만 써서, 이름이나 숨김 설정이 다른 터미널의 옛 값에 덮이지 않습니다. 코인은 양쪽에서 늘고 준 만큼을 모두 더합니다 |

레포는 마켓플레이스 하나에 두 폴더로 나뉩니다.

| 경로 | 내용 |
|---|---|
| `.claude-plugin/marketplace.json` | 이 레포를 마켓플레이스로 만드는 파일 |
| `plugin/` | 토코 모드. 설치하면 이 폴더만 쓰입니다 |
| `server/` | 광장 서버. 의존성 없는 Bun 프로그램 하나(`plaza.ts`)와 현황 페이지(`page.html`)입니다 |

## 쓰는 법

### 띠와 단축키

프롬프트 위 띠에 펫이 삽니다. 띠를 클릭하거나 ctrl+x tab으로 포커스를 주면 단축키를 쓸 수 있습니다.

| 키 | 동작 |
|---|---|
| f | 먹이 주기. 간식이 없으면 코인으로 쿠키를 삽니다 |
| p | 같이 놀기 |
| r | 토코의 방 열기 |
| 1 · 2 · 3 | 권유에 답하기: 좋아 · 나중에 · 오늘은 그만 |
| o | 선물 상자 열기 |
| a · s · d | 벌레 잡기 미니게임: 왼쪽 · 잡기 · 오른쪽 |

### 이름 짓기

알이 깨지면 펫이 이름을 지어 달라고 말을 겁니다. 1을 누르면 입력란에 `/toko name `이 채워지니 이름만 쓰고 보내면 됩니다. 2를 누르면 작은 모델이 지어 둔 이름을 그대로 씁니다. 답하지 않아도 이 물음은 사라지지 않고, 이름이 정해질 때까지 띠에는 "이름 없음"으로 보입니다. 이름은 띄어쓰기 없는 한 낱말에 12자까지이고, `/toko name <새 이름>`으로 언제든 바꿀 수 있습니다.

### 쉬자는 권유

틈이 오면 토코가 지금 상황에 맞는 권유를 하나 고릅니다. 가만히 있는 쪽을 고르기도 합니다. 30초 동안 아무것도 누르지 않으면 조용히 물러나고, 거절로 세지 않습니다.

| 권유 | 조건 |
|---|---|
| 기지개 | 쉬지 않고 일한 시간이 휴식 간격(기본 50분)을 넘었습니다 |
| 먼 곳 보기 | 20분마다 20초 동안 화면 밖을 봅니다 |
| 물 한 모금 | 하루 3번 이내 |
| 일찍 쉬기 | 사용 한도가 80%를 넘었거나 밤이 늦었습니다 |
| 복귀 브리핑 | 10분 넘게 자리를 비웠다 돌아오면 하던 일을 한 줄로 짚어 줍니다 |
| 막힘 풀기 | 같은 테스트가 세 번 이어서 실패하면 2분만 일어났다 오자고 하고, 돌아오면 실패 요약을 보여 줍니다 |
| 마무리 정리 | 정한 퇴근 시각이 지나면 오늘 한 일을 정리해 기록에 남깁니다 |
| 다 같이 기지개 | 광장에 친구가 있으면 함께 기지개를 켭니다 |
| 선물 · 벌레 잡기 · 수다 | 하루 1~2번 깜짝 선물, 테스트를 통과시킨 직후 30초 놀이, 오래 말이 없을 때 한마디 |

Claude의 턴이 1분을 넘기면 말풍선 없이 20초짜리 먼 곳 보기 카운트다운만 띄웁니다.

### 랜덤 인카운터

작업 중이거나 잠깐 손을 쉬는 동안, 6분에 한 번쯤 띠에 작은 장면이 지나갑니다. 말을 걸지 않고 눈을 쉬게 하는 장면들입니다.

| 장면 | 때 |
|---|---|
| 나비 따라가기 | 낮 |
| 떨어지는 잎 보며 앉아 있기 | 언제나 |
| 토큰 부스러기 냠 | 일하는 중에 자주 |
| 비눗방울 불기(숨을 들이쉬고 길게 내쉬기) | 걱정이 많은 날에 자주 |
| 별똥별 보기 | 저녁과 밤 |
| 비구름과 우산 | 언제나 |
| 새싹에 물 주기 | 쉬는 중에 자주 |
| 반딧불이 | 저녁과 밤 |

처음 본 장면은 인카운터 도감에 올라가고 5코인을 받습니다. 16번에 한 번꼴로 반짝이가 붙은 장면이 나오는데, 종류마다 처음 보면 15코인을 더 받고 도감에 ✦가 붙습니다. 나비는 낮에만, 별똥별과 반딧불이는 저녁과 밤에만 나오니 다 모으려면 여러 시간대에 써야 합니다. `/toko dex`나 방에서 도감을 봅니다.

### 분풀이

Claude가 엉뚱한 일을 했을 때 이유 한 줄과 함께 부탁합니다.

```text
/bonk 테스트 지우지 말랬잖아
```

토코가 뿅망치를 들고 달려가 때립니다. 턴이 도는 중이면 스피너가 "아야…"로 바뀌고, 턴이 없으면 말풍선 인형을 꺼내 놓고 때립니다. 끝나면 토코가 Claude에게 짧은 메시지를 보내고, Claude는 "아야…"로 받아들인 뒤 바로잡고 사과 도구를 부릅니다. 마지막에는 숨 고르기(4초 들이쉬고 6초 내쉬기)나, 불만을 정중한 교정 문장으로 다듬어 다음 프롬프트에 넣기를 고릅니다. 화풀이로 끝내지 않고 진정이나 교정으로 끝내려는 장치입니다.

같은 잘못으로 또 때리면 토코가 Claude에게 그 내용을 auto memory에 피드백으로 남겨 달라고 덧붙입니다. 토코는 최근 뿅망치 이유 20개를 기억해 두고, 새 이유가 그중 하나와 같은 종류인지 작은 모델에게 물어봅니다(모델을 끄면 글자가 많이 겹치는지로 봅니다). 처음 맞은 이유는 바로잡고 사과받는 걸로 끝내고, 두 번째부터만 기억시킵니다. CLAUDE.md는 세션마다 통째로 읽혀서 쌓일수록 무거워지니, CLAUDE.md에는 쓰지 말고 비슷한 메모가 있으면 그걸 고치라고 함께 부탁합니다. 이럴 때는 마지막 말풍선이 "또 같은 일이라 기억해 두라고 했어"로 시작합니다. Claude Code의 `/memory`에서 Auto-memory가 켜져 있어야 남습니다.

### 코인과 성장

턴이 정상으로 끝나면 출력 토큰으로 코인을 법니다. 공식은 `round(9 × log2(1 + 출력 토큰 / 500))`이고, 캐시를 절반 넘게 읽은 턴은 1.2배입니다. 토큰 수입은 하루 500코인에서 멈춥니다. 펫이 스스로 부른 모델 사용량은 수입에 넣지 않습니다.

| 출력 토큰 | 코인 |
|---|---|
| 500 | 9 |
| 1,500 | 18 |
| 7,500 | 36 |
| 50,000 | 60 |

기지개를 받아들이면 15코인, 먼 곳 보기를 끝까지 하면 5코인, 마무리 정리는 20코인입니다. 휴식 보상은 하루 상한 밖입니다. 펫은 알 → 아기 → 어린이 → 어른으로 자라는데, 기준은 쓴 토큰이 아니라 함께한 날 수와 받아들인 휴식 수입니다.

### 애완동물

상점의 애완동물 칸에서 작은 동물을 데려올 수 있습니다. 병아리는 60코인, 햄스터는 90코인, 아기 토끼는 100코인, 아기 고양이와 강아지는 120코인입니다. 데려온 동물은 띠에서 토코 뒤를 졸졸 따라다닙니다. 토코가 앉으면 같이 앉고, 잠들면 같이 눈을 감습니다. 방에서는 토코 옆에 앉아 있습니다. 한 번에 한 마리만 데리고 다니고, 바꾸는 법은 모자와 같습니다. 꾸미기에서 고르거나 `/toko wear <id>`를 쓰면 됩니다. 밥을 챙기지 않아도 굶거나 떠나지 않습니다.

### 패션 · 애완동물 뽑기

모자(털모자 · 리본 · 작은 왕관 · 야구모자 · 베레모 · 꽃핀 · 고깔모자), 목에 거는 것(목도리 · 나비넥타이), 안경(동그란 안경 · 선글라스 · 하트 안경)은 상점에서 팔지 않고 패션 뽑기로만 얻습니다. 이미 가진 것은 그대로 입을 수 있습니다. 안경은 종족마다 다른 눈 위치에 맞춰 씌웁니다. `/toko gacha fashion`과 `/toko gacha pet`은 각각 50코인이고, 아직 없는 것 중에서 하나가 무작위로 나와 바로 입거나 데려옵니다. 다 모았으면 코인을 받지 않습니다. 방의 뽑기 칸에도 같은 단추가 있습니다.

### 펫 뽑기

코인 200개로 새 펫을 뽑습니다. 새 펫은 알로 나와 바로 깨어나고, 이름과 성격은 처음 알을 깰 때처럼 새로 짓습니다. 지금 데리고 다니던 펫은 보관함으로 가고, 보관함의 펫은 언제든 다시 데리고 다닐 수 있습니다. 성장 단계 · 이름 · 성격은 펫마다 따로 남습니다. 배고픔 같은 상태와 펫이 배운 내 습관은 모든 펫이 함께 씁니다.

| 등급 | 확률 | 종족 |
|---|---|---|
| 노말 | 90% | 고양이 · 곰 · 병아리 · 토끼 · 개구리 · 펭귄 · 여우 · 용 |
| 레어 | 10% | 유니콘 · 유령 · 불사조 · 로봇 · 우파루파 |

등급을 먼저 정하고, 그 등급 안에서는 종족마다 확률이 같습니다. 이미 가진 종족이 나오면 꽝이라 코인만 쓰고 끝납니다. 13종을 다 모으면 더는 뽑지 않고 코인도 빼지 않습니다. 종족이 생기기 전에 키우던 펫은 고양이로 이어집니다.

### 업적과 오늘의 퀘스트

업적은 22개입니다. 휴식(첫 쉼표 · 쉼표 수집가 · 먼 산 바라기 등), 개발(역전승 · 첫 머지 · 백 걸음 등), 습관과 놀이(몰입의 시간 · 정시 퇴근 · 도감 완성 등), Claude Code 기능(기능 수집가 · Claude Code 탐험가)으로 나뉘고, 한 번 달성하면 계속 남으며 10~80코인을 받습니다. 역전승은 세 번 이상 실패한 테스트를 끝내 통과시켰을 때입니다. 토큰을 많이 쓴 걸로 주는 업적은 없습니다.

오늘의 퀘스트는 매일 쉬기 · 일 · 돌봄에서 하나씩 세 개가 나옵니다. 날짜와 펫으로 정해지므로 터미널을 여러 개 켜도 같은 퀘스트가 나오고, 진행도도 합쳐서 셉니다. 하나 끝낼 때마다 5코인, 셋 다 하면 10코인과 선물 상자를 받습니다. 못 끝낸 퀘스트는 다음 날 바뀔 뿐 잃는 건 없습니다. 띠 상태줄에 "퀘스트 1/3"으로 보이고, `/toko quests` · `/toko badges`나 방에서 자세히 봅니다.

### 집중 타이머

`/toko focus`로 25분 집중을 시작합니다(`/toko focus 50`처럼 5~120분). 집중하는 동안에는 권유 · 말풍선 · 랜덤 장면이 멈추고 띠에 남은 시간만 보입니다. 끝까지 하면 10코인을 받고, 다음 틈에 기지개를 권합니다. `/toko focus off`로 멈추면 보상은 없습니다. 방에도 시작과 그만하기 버튼이 있습니다.

### 컨텍스트 · 비용 미터

띠 버튼 줄 오른쪽에 "컨텍스트 62% · $1.24 · 5시간 41%"를 보여 줍니다. Claude Code가 상태줄과 `/cost`에 쓰는 숫자 그대로이고, 사용 한도는 가장 많이 찬 창을 고릅니다. 컨텍스트 70% · 한도 75%부터 노란색, 컨텍스트 85% · 한도 90%부터 빨간색이 되고, 한도가 80%를 넘으면 리셋 시각을 붙입니다. 띠를 숨겨도 프롬프트 힌트 끝에 컨텍스트 %가 남습니다. 상태줄을 따로 쓰면 `/toko meter off`로 끕니다.

### 생각 주차장 메모

Claude가 일하는 동안 떠오른 딴생각을 `/memo 로그 포맷도 바꾸기`처럼 맡겨 둡니다. 턴이 도는 중에도 바로 받습니다. 턴이 끝난 틈에 토코가 "아까 맡긴 메모: …"를 꺼내고 입력창에 넣을지 묻습니다. 넣기는 쓰던 글 뒤에 붙이기만 하고 보내지는 않습니다. 나중에를 누르면 30분 뒤에 다시 꺼냅니다. 메모는 내 컴퓨터에만 두고 광장이나 모델로 보내지 않습니다.

### 오늘 한 일 요약

`/toko today`는 오늘 커밋 · PR · 테스트 · 편집 줄 수 · Claude 턴과 비용 · 휴식 · 집중 · 남은 메모를 몇 줄로 정리해 클립보드에 넣습니다. 여러 터미널의 기록을 합친 하루 기준이라 스탠드업이나 Jira 댓글에 그대로 붙여 넣으면 됩니다. 방의 [오늘 기록 복사] 버튼도 같습니다.

- 커밋 5번 · 푸시 2번 · PR 머지 1번

- 테스트 통과 7번 · 실패 3번

### Claude Code 새 기능 소개

Claude Code가 업데이트되면 토코가 새로 생긴 기능 하나를 골라 쉬운 말로 알려 줍니다. 세션을 열고 8초쯤 뒤에 Claude Code 공식 CHANGELOG를 읽고, 지난번에 본 버전 다음부터 생긴 기능 가운데 터미널에서 코딩하는 사람 누구에게나 쓸모 있는 것 하나를 작은 모델이 고릅니다. 클라우드 세션 · 회사 설정 · 텔레메트리 · SDK · 모드 개발용 기능은 고르지 않습니다. 업데이트가 거의 매일 나오지만 대부분 버그 수정이라, 새 기능이 없는 업데이트에는 아무 말도 하지 않습니다. 처음 설치했을 때는 최근 다섯 번의 업데이트에서 하나를 고릅니다.

다음 틈에 토코가 "Claude Code 2.1.304에 새 기능이 생겼어: /auto-mode-setup. 들어 볼래?"처럼 묻습니다. 1(알려 줘)을 누르면 무엇을 해 주는지, 언제 쓰면 좋은지를 대화창에 적고, 바로 해 볼 명령이 있으면 비어 있는 입력창에 넣어 둡니다. 2(나중에)는 30분 뒤에 다시 묻고, 3(안 볼래)은 그 소개를 넘깁니다. 한 버전은 한 번만 소개하고, 터미널을 여러 개 켜도 한 곳에서만 묻습니다. `/toko ai off`이면 소개를 건너뜁니다. 지난 소개는 `/toko news`나 방에서 다시 봅니다.

### 기능 도감

Claude Code 기능을 처음 써 볼 때마다 기능 도감에 도장이 찍히고 5코인을 받습니다. 쓸 줄 아는 기능이 늘어나는 걸 모으는 장치입니다. 모두 16가지이고, 8가지를 쓰면 기능 수집가, 16가지를 다 쓰면 Claude Code 탐험가 업적을 받습니다.

| 기능 | 이렇게 써요 |
|---|---|
| 대화 줄이기 · 새로 시작 · 이어 하기 · 되감기 | `/compact` · `/clear` · `/resume`(셸에서 `claude -c`도 됩니다) · `/rewind` |
| CLAUDE.md 만들기 · 메모리 보기 · 허용 규칙 | `/init` · `/memory` · `/permissions` |
| 모델 바꾸기 · 컨텍스트 보기 · 세션 이름 짓기 | `/model` · `/context` · `/rename` |
| 코드 리뷰 · 되풀이 맡기기 | `/code-review` · `/loop` |
| 계획 먼저 · 뒤에서 돌리기 | Shift+Tab으로 plan mode를 켜고 계획을 받기 · Ctrl+B로 명령을 뒤로 보내기 |
| 그림 붙여 넣기 · 파일 짚기 | Ctrl+V로 화면 캡처 붙여 넣기 · `@파일` |

명령은 내가 직접 입력했을 때만 셉니다. 계획 먼저는 Claude가 plan mode에서 계획을 내밀 때, 뒤에서 돌리기는 명령이 백그라운드로 돌 때 찍힙니다. 단축키 자체는 토코가 보지 못해서, 되감기를 Esc 두 번으로만 하면 도장이 찍히지 않습니다. `/toko features`나 방에서 아직 안 써 본 기능과 쓰는 법을 봅니다.

### 상황별 팁

아직 안 써 본 기능이 딱 맞는 순간이 오면, 토코가 틈에 그 기능을 한 번 권합니다. 1(써 보기)을 누르면 비어 있는 입력창에 명령을 넣어 두고, 3(알아)을 누르면 그 팁은 다시 하지 않습니다. 같은 팁은 하루에 한 번만 하고, 기능 도감에 오른 기능은 권하지 않습니다. 말풍선은 다른 권유와 같이 시간당 4번 안에서만 띄웁니다.

| 이럴 때 | 권하는 것 |
|---|---|
| 컨텍스트가 80%를 넘었을 때 | `/compact`로 대화를 요약해서 비우기 |
| 같은 명령의 권한 확인을 세 번째 받았을 때 | `/permissions`에 허용 규칙 넣기 |
| `/bonk`가 끝났을 때 | `/rewind`로 아까 시점으로 되돌리기 |
| CLAUDE.md가 없는 레포에서 세션을 열었을 때 | `/init`으로 CLAUDE.md 만들기 |
| "끝났어?", "다시 확인해 줘" 같은 부탁을 한 시간에 세 번 했을 때 | `/loop`로 되풀이 맡기기 |
| 커밋하고 아직 푸시하지 않았을 때 | `/code-review`로 리뷰받기. 그사이 푸시하면 권하지 않습니다 |

### 종족별 말투

펫은 종족마다 성격과 말투가 다릅니다. 알을 깰 때 작은 모델이 종족에 어울리는 성격과 말버릇을 짓고, 그 뒤로 모델이 쓰는 대사도 모두 종족 말투를 따릅니다. 모델을 끄거나 하루 호출 한도를 다 써도 말투는 그대로입니다. 준비된 대사에 종족 말투를 입혀 말합니다. 고양이는 말끝을 바꾸고, 곰 · 용 · 유령 · 로봇은 소리로 말을 꺼내고, 나머지 종족은 말끝에 소리를 붙입니다. 몇몇 대사는 종족에 맞게 따로 써 두었습니다.

| 종족 | 성격 | 말투 예 |
|---|---|---|
| 고양이 | 도도해 보여도 늘 곁에 붙어 있는 느긋한 고양이 | 같이 기지개 한 번 켤래냥? |
| 곰 | 서두르지 않고 기대어 쉴 품을 내어 주는 곰 | 음… 겨울잠까진 아니어도 오늘은 일찍 쉬자 |
| 병아리 | 작은 일에도 크게 기뻐하는 수다쟁이 병아리 | 통과다! 삐약삐약! |
| 토끼 | 작은 기척에도 귀를 쫑긋 세우는 수줍은 토끼 | 오래 앉아 있었네. 같이 깡충 뛰어 볼래? |
| 개구리 | 연잎 위에서 멍하니 쉬는 데 선수인 개구리 | 개굴, 물 한 모금 어때? 난 벌써 촉촉해 |
| 펭귄 | 줄을 맞춰 차례대로 하는 꼼꼼한 펭귄 | 20초만 먼 바다 보자. 내가 세어 줄게 펭! |
| 여우 | 네가 지친 걸 먼저 알아채는 눈치 빠른 여우 | 꾀가 안 날 땐 잠깐 쉬는 게 꾀야. 캥 |
| 용 | 겉은 위풍당당하지만 속은 여린 꼬마 용 | 크릉, 불은 내가 대신 뿜을게. 넌 숨만 고르자 |
| 유니콘 | 작은 일도 마법처럼 기뻐해 주는 유니콘 | 반짝반짝, 별가루 선물이야. o 눌러서 열어 봐 |
| 유령 | 겁주지 않고 살며시 곁에 머무는 수줍은 유령 | 스르르… 놀랐어? 오늘도 옆에 있을게 |
| 불사조 | 실패해도 괜찮다고 다독이는 따뜻한 불사조 | 한 번 더 하면 돼. 화르륵! |
| 로봇 | 다정함을 하나씩 배워 가는 성실한 로봇 | 삐빅. 수분 보충 시각이야. 물 한 잔 어때? |
| 우파루파 | 늘 웃는 얼굴로 천천히 사는 우파루파 | 뽀글, 물은 내 집이야. 너도 한 모금 마셔 |

### 토코와 이야기하기

`/toko 안녕!`, `/toko 오늘의 퀘스트는 뭐야?`처럼 정해진 명령이 아닌 말을 쓰면 토코에게 말을 겁니다. 답은 따로 모델을 부르지 않고 지금 세션의 Claude가 토코가 되어 하므로, 세션과 같은 토큰을 씁니다. Claude는 펫 카드 · 기분 · 욕구 · 코인 · 오늘의 퀘스트 · 오늘 한 일을 숨은 메모로 받아 그 안에서만 답하고, 답의 첫 줄은 띠의 말풍선에도 뜹니다. 메모 내용은 개수만 넘깁니다.

"간식 줘", "25분 집중할게"처럼 해 달라는 말이면 Claude가 `mcp__toko__command` 도구로 맞는 명령을 대신 실행합니다. `mute`, `quests` 같은 정해진 명령은 지금처럼 모델 없이 바로 실행됩니다.

### 명령

| 명령 | 동작 |
|---|---|
| `/toko <하고 싶은 말>` | 토코에게 말을 겁니다. 지금 세션의 Claude가 토코가 되어 답합니다 |
| `/toko` | 토코의 방(퀘스트 · 업적 · 도감 · 메모 · 상점 · 꾸미기 · 펫 뽑기 · 광장)을 엽니다 |
| `/toko help` | 명령 목록 |
| `/toko mute` · `unmute` | 말 걸기를 끄고 켭니다 |
| `/toko hide` · `show` | 띠를 숨깁니다. 쉬자고 할 때만 잠깐 나타납니다 |
| `/toko quiet 22-09` | 방해 금지 시간 |
| `/toko break 50` | 휴식 권유 간격(분) |
| `/toko off-work 19` | 퇴근 시각. 지나면 마무리 정리를 권합니다 |
| `/toko ai off` | 작은 모델을 부르지 않습니다. 규칙과 준비된 대사로만 움직입니다 |
| `/toko notify on` | 집중 타이머가 끝나면 OS 알림을 하루 3번까지 보냅니다(기본 꺼짐) |
| `/toko shop` · `buy <id>` · `wear <id>` | 상점과 꾸미기. 애완동물도 여기서 데려오고 바꿉니다 |
| `/toko card` | 펫 카드 |
| `/toko name <이름>` | 펫 이름을 짓거나 바꿉니다 |
| `/toko draw` | 코인 200개로 펫을 뽑습니다 |
| `/toko gacha fashion` · `gacha pet` | 코인 50개로 안 가진 패션 아이템이나 애완동물을 하나 뽑습니다 |
| `/toko pets` · `pick <번호\|이름>` | 보관함을 보고, 같이 다닐 펫을 바꿉니다 |
| `/toko quests` · `badges` · `dex` | 오늘의 퀘스트 · 업적 · 인카운터 도감 |
| `/toko focus 25` · `focus off` | 집중 타이머. 그동안 말을 걸지 않습니다 |
| `/toko meter on` · `off` | 띠의 컨텍스트 · 비용 · 한도 미터 |
| `/toko memo <내용>` · `memo` · `memo clear` | 생각 주차장 메모. `/memo <내용>`도 같습니다 |
| `/toko today` | 오늘 한 일을 정리해 클립보드에 넣습니다 |
| `/toko news` | 지금까지 소개한 Claude Code 새 기능을 다시 봅니다 |
| `/toko features` | 기능 도감. 써 본 기능과 아직 안 써 본 기능의 쓰는 법을 봅니다 |
| `/toko event <종류>` | 권유나 장면을 바로 띄웁니다(시연용). 예: `/toko event butterfly shiny`, `/toko event update`(새 기능 소개) |
| `/toko plaza` · `plaza wave <이름>` · `plaza invite` | 광장 |
| `/bonk <이유>` · `/feed` · `/play` · `/memo <내용>` | 분풀이 · 먹이 · 놀기 · 메모 맡기기 |

Claude는 세 도구를 씁니다. 펫 상태를 묻는 `mcp__toko__pet_status`, 분풀이를 당한 뒤 사과하는 `mcp__toko__apologize`, 토코와 이야기하다 해 달라는 일을 명령으로 실행하는 `mcp__toko__command`입니다.

Claude Code의 움직임 줄이기 설정이 켜져 있으면 정지 그림만 그립니다. `NO_COLOR`, 60열보다 좁은 화면, 낮은 띠에서는 한 줄 글로 바뀝니다.

## 광장 서버

광장은 같은 서버에 접속한 사람들의 펫이 만나는 곳입니다. 플러그인의 `serverUrl` 기본값이 팀 광장(`https://toko-plaza.dllm.dable.io`)이라서 설치하면 바로 들어갑니다. 이 주소는 사내망에서만 열립니다. 나가고 싶으면 `/toko plaza off`를 쓰고, 다른 광장을 쓰려면 `claude plugin configure toko --config serverUrl=<광장 주소>`로 바꿉니다. 비워 두면 토코는 혼자 지냅니다.

```bash
cd server
bun run plaza.ts                 # http://0.0.0.0:8080
docker build -t toko-plaza .     # 컨테이너로 띄울 때. uid 1000, HOME=/app으로 돕니다
```

`GET /`는 광장을 화면 전체에 픽셀 마을로 그리는 현황 페이지입니다. 들어온 펫이 각자의 모습 그대로 분수대 광장을 돌아다니고, 이름표에 상태(일하는 중 · 쉬는 중 · 잠깐 멈춤 · 자리 비움)가 붙습니다. 새로 들어온 펫은 길을 따라 걸어 들어와 "놀러 왔어!"라고 말하고, 손짓을 보내면 그 대사가 말풍선으로 뜹니다. 저녁에는 노을이 지고 밤에는 가로등과 창문 불빛이 켜집니다. 그림을 보내지 않는 옛 플러그인의 펫은 같은 색의 기본 모양으로 그립니다. 페이지는 `GET /v1/plaza/stream`(SSE)으로 광장이 바뀔 때마다 공개 현황(광장 id를 뺀 JSON)을 바로 받습니다. 같은 내용을 한 번 읽는 `GET /v1/plaza`도 있고, `GET /health`는 상태 확인용입니다.

플러그인 쪽은 `/plugin` → 토코 → 설정에서 `serverUrl`을 `http://<서버 주소>:8080`로 바꿉니다.

펫끼리 건네는 짧은 인사말은 작은 모델이 씁니다. 서버는 아래 순서로 대사를 만들 길을 고릅니다.

1. `TOKO_DLLM_URL`이 있으면 그 OpenAI 호환 게이트웨이(`chat/completions`)를 부릅니다.
2. 없고 `CLAUDE_CODE_OAUTH_TOKEN`이 있으면 컨테이너 안의 Claude Code CLI(`claude -p --model haiku`)를 부릅니다. 배포 환경이 Claude Code OAuth 토큰을 넣어 주는 경우이고, 한 번에 두 개까지만 돌립니다.
3. 둘 다 없거나 답이 늦으면 준비된 대사로 대신합니다.

손짓을 보내면 서버는 바로 접수(202)하고, 대사는 뒤에서 만들어지는 대로 광장에 올립니다. 토코는 `curl -N`으로 `GET /v1/stream`(SSE)을 열어 두고 친구 목록과 손짓을 오는 즉시 받습니다. 연결이 열려 있는 동안은 광장에 있는 것으로 치고, 상태나 생김새가 바뀔 때만 `POST /v1/poll`로 알립니다. 연결이 끊기면 1초부터 최대 60초까지 간격을 늘려 다시 붙고, 그동안과 `curl`을 띄울 수 없는 환경에서는 20초마다 광장을 확인합니다.

| 변수 | 뜻 |
|---|---|
| `PORT` | 서버 포트. 기본 8080 |
| `TOKO_DLLM_URL` | LLM 게이트웨이의 OpenAI 호환 주소. 예: `https://<게이트웨이>/v1` |
| `TOKO_DLLM_MODEL` | 게이트웨이의 모델 이름. 작은 모델(Haiku 급)을 권합니다 |
| `TOKO_DLLM_KEY` | 게이트웨이 키. 서버 환경 변수로만 두고 레포에 넣지 않습니다 |
| `TOKO_DLLM_TIMEOUT_MS` | 게이트웨이 응답을 기다리는 시간. 기본 2500 |
| `CLAUDE_CODE_OAUTH_TOKEN` | Claude Code CLI로 대사를 만들 때 쓰는 토큰. 배포 환경의 시크릿으로 넣습니다 |
| `TOKO_CLAUDE_MODEL` | Claude Code CLI의 모델. 기본 haiku |
| `TOKO_CLAUDE_TIMEOUT_MS` | Claude Code CLI를 기다리는 시간. 기본 20000 |

광장에 보내는 정보는 펫 이름 · 종족 · 기분 · 상태(일하는 중 · 쉬는 중 · 자리 비움) · 생김새(현황 페이지에 그릴 작은 픽셀 그림) · 탭 표시(터미널을 켤 때마다 새로 뽑는 임의 값) · 입은 것(모자 · 목에 거는 것 · 안경의 아이템 id)뿐입니다. 손짓 · 하트를 받은 쪽에 찾아가는 펫은 보낸 사람이 입은 것을 그대로 입고 갑니다. 생김새는 다른 펫에게 돌려주지 않고 현황 페이지에만 씁니다. 한 사람이 터미널을 여럿 띄우면 서버는 가장 바쁜 터미널의 상태와 생김새를 보여 주고, 45초 동안 소식이 없는 터미널은 셈에서 뺍니다. 코드, 프롬프트, 파일 이름은 보내지 않습니다. 서버는 모든 것을 메모리에만 두고, 90초 동안 소식이 없는 펫은 광장에서 지웁니다. 손짓은 한 사람이 1분에 12번까지만 보낼 수 있습니다.

## 개발과 검증

```bash
claude plugin validate plugin   # 매니페스트와 훅 모듈을 엔진이 읽는 방식으로 검사
claude plugin test plugin       # 플러그인 테스트 139개(경제 · 터미널 사이 동기화 · 게이트 · 렌더링 · 애완동물 · 분풀이 · 이름 짓기 · 광장 · 옆 세션 소식 · 뽑기 · 업적 · 퀘스트 · 집중 · 도감 · 미터 · 메모 · 오늘 요약 · 종족 말투)
cd server && bun test           # 광장 서버 테스트 14개
```

개발 중에는 `claude --plugin-dir ./plugin`으로 띄우면 파일을 저장할 때마다 다시 로드됩니다.
